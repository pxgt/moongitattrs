# Third-party and reference notice

MoonGitAttrs is an original MoonBit implementation based on publicly documented
Git behavior. No source code from Git or another `.gitattributes` parser is
included in this repository.

Behavioral reference:

- Project: Git
- Documentation: <https://git-scm.com/docs/gitattributes>
- Git license information: <https://git-scm.com/about/free-and-open-source>

The runtime dependency `moonbitlang/x` is maintained by the MoonBit project and
is used only by the native CLI for file and process access. Its package metadata
and license are available from Mooncakes.
